# Ocho Paws Remembrance Altar

Rol: Eres un diseñador UX/UI y desarrollador web senior fronted con experiencia en desarrollo en páginas creativas.



TAREA: crea una landing page para hacer un altar digital para mis mascotas, las cuales son una perrita pastor aleman adulta llamada Hanna cafe claro con negro y blanco, Un pastor aleman black solid de 5 meses de edad llamado Max color negro solido, Un pastor aleman cafe claro con negro adulto llamado DIX, Un pastor aleman cafe gris con negro adulto llamado Mozart y Un perrito cruza de maltes con shutzu negro con gris llamado Chester, Tres perritos salchichas cafes de pelo corto llamados Clara, Toto y Camila



CONTEXTO:

Las caracteristicas de la landing page son:

-Paleta de colores tradicional:morado, naranja, flores de cempasuchil.

-que sea interactiva al momento de pasar el cursor por algun detalle se agrande

-petalos de cempasúchil cayendo

-que inicie a enseñar la web al apretar la nariz de un perro como botón.

-Las fotos de mis perritos hazlas animadas.

-un arco colgando de la parte de arriba de cada imagen de perrito, este será de flores de cempazuchitl

-Guirnaldas de papel picado de colores animada en el encabezado.

-veladoras encendidas que la llama se mueva como si el aire la solpara

 -Que el cursor sea en forma de patita o huellita
